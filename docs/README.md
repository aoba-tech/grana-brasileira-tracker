# Documentação do Pila

Este diretório concentra o contexto necessário para desenvolver e manter a
aplicação.

## Índice

- [Referência do projeto](./PROJECT.md): visão funcional, stack, arquitetura,
  modelo de dados, convenções e roadmap.
- [Guia de continuidade](./HANDOFF.md): estado atual da implementação,
  decisões recentes, pendências e comandos para continuar no Codex Desktop.

## Fonte de verdade

O código e os testes são a fonte de verdade. Atualize estes documentos na mesma
alteração sempre que uma decisão arquitetural, fluxo de desenvolvimento ou
funcionalidade descrita aqui mudar.
